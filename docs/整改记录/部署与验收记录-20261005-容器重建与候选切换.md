## 5. 本轮新增发现（不扩大修改，仅记录）

- `scripts/diagnose_writer_tdengine_capability.py` 的 `--allow-host` 是**未接线的死开关**：白名单
  `ALLOWED` 只含 `perf-redis/perf-mysql/perf-td`，脚本在本机**无法运行**；且硬编码 TDengine 默认口令、
  MySQL 空口令。它在隔离 perf 栈之外的可用性为零——建议后续要么接线 `--allow-host`，要么在文档中明确其前置。
- `taosdump` 要求输出目录**预先存在**，否则报 `is not exist`（首次运行因此失败）。
- 手工启动已安装 Writer 需要**两个上下文**：工作目录=<数据根>`\writer`（否则找不到 `config/settings.toml`），
  以及 Agent 注入的 `DATAWATCH_<DB>_<FIELD>` 环境凭据（否则 Redis 认证失败）。建议在运维文档中写明。
- TDengine 3.4 上 `min(ts)` 报 `Invalid parameter data type : min`（用 `first(ts)`/`last(ts)` 替代）。
