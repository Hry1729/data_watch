DataWatch 系统架构详图

工业设备数据采集与监控平台 · 模块内部组件与数据流

采集与入库解耦

  • • collector 与 writer 无代码级调用，仅经 Redis 传递数据
  • • 写序不变式：window/stream 成功后才刷新 latest
  • • writer：LANDED 才 ACK，坏数据进 DLQ 才 ACK，其余 RETRY

三库分工

  • • MySQL device_watch：拓扑 / RBAC / 日志 — 配置事实源
  • • Redis：latest 实时 / window 短窗 / stream 入库队列 / dlq 死信
  • • TDengine device_data：时序历史宽表，列只增不减

边缘与安全

  • • agent 是边缘中枢：进程管控 + DPAPI 凭据单一来源 + sidecar 编排
  • • OPC DA 走 C# x86 sidecar，与 64 位 Python 主链路隔离
  • • 双根路径：INSTALL_ROOT 只读 / DATA_ROOT 可写

双前端分工

  • • frontend (Vue3 Web)：业务控制台 — 实时/历史/管理
  • • app (Tauri 桌面)：边缘运维 — 首装/启停/指标/日志
  • • app 经 Rust 壳转发 HTTP，规避 CORS；后端地址运行期注入
