# 后端项目结构

> 范围：`backend/`。本文件只展开后端业务源码与关键配置；`.py314t-site`、`.pip-temp` 等依赖/临时目录不展开。

```text
backend
├── .py314t-site           # 本地 Python 3.14t 依赖目录，按依赖处理
├── .pip-temp              # pip 临时安装目录，按临时缓存处理
├── app                    # 后端应用源码
│   ├── api                # API 路由层与权限定义
│   │   ├── routes         # 具体业务路由模块
│   │   │   ├── __init__.py
│   │   │   ├── auth.py            # 登录、登出、当前用户信息等认证接口
│   │   │   ├── catalog.py         # 驱动、设备、点位等配置类接口
│   │   │   ├── dashboard.py       # 工作台统计、趋势、告警分布等接口
│   │   │   ├── history.py         # 历史数据查询、导出、下载接口
│   │   │   ├── log.py             # 系统日志、操作日志、清理策略接口
│   │   │   ├── module_monitor.py  # collector/writer 监控指标与速率接口
│   │   │   ├── monitor.py         # 实时监控 HTTP 接口与 WebSocket 注册
│   │   │   ├── perspective.py     # Perspective 历史分析会话接口
│   │   │   ├── system.py          # 健康检查、ping 等系统基础接口
│   │   │   └── system_manage.py   # 用户、角色、菜单、按钮权限接口
│   │   ├── __init__.py
│   │   ├── permissions.py         # 权限码、权限依赖与校验逻辑
│   │   └── router.py              # 路由聚合入口
│   ├── core               # 核心基础能力
│   │   ├── __init__.py
│   │   ├── audit.py               # 审计上下文与操作记录辅助逻辑
│   │   ├── config.py              # 后端配置加载与环境变量解析
│   │   ├── exceptions.py          # 统一异常类型与异常处理
│   │   ├── log_scheduler.py       # 日志清理/调度逻辑
│   │   ├── log_writer.py          # 日志写入辅助逻辑
│   │   ├── logging.py             # 日志系统初始化
│   │   ├── responses.py           # 统一响应结构
│   │   ├── security.py            # JWT、密码、安全相关工具
│   │   ├── simple_xlsx.py         # 简单 Excel 导入/导出工具
│   │   ├── status_thresholds.py   # 状态阈值与在线/离线判定规则
│   │   └── time_utils.py          # 时间格式化与时间范围工具
│   ├── db                 # 数据库连接层
│   │   ├── __init__.py
│   │   ├── mysql.py               # MySQL 连接、会话与查询辅助
│   │   ├── redis.py               # Redis 客户端与实时态读取
│   │   └── tdengine.py            # TDengine 连接与历史查询辅助
│   ├── models             # ORM / 数据库模型
│   │   ├── __init__.py
│   │   ├── auth.py                # 用户、角色、菜单、权限等认证模型
│   │   ├── base.py                # ORM 基类与公共字段
│   │   └── log.py                 # 系统日志、操作日志、日志策略模型
│   ├── schemas            # Pydantic/接口数据结构
│   │   ├── __init__.py
│   │   └── auth.py                # 认证相关请求/响应模型
│   ├── services           # 业务服务层
│   │   ├── __init__.py
│   │   ├── auth.py                # 登录、用户信息、权限装载逻辑
│   │   ├── auth_bootstrap.py      # 默认用户/角色/权限种子初始化
│   │   ├── catalog.py             # 驱动、设备、点位业务逻辑
│   │   ├── dashboard.py           # 工作台统计和趋势计算
│   │   ├── history.py             # 历史查询、降采样、导出任务逻辑
│   │   ├── log.py                 # 日志查询、统计、策略与清理逻辑
│   │   ├── module_monitor.py      # collector/writer 模块指标聚合
│   │   ├── monitor.py             # 实时监控初始化和窗口查询逻辑
│   │   ├── perspective.py         # Perspective 会话与历史查询桥接
│   │   ├── rate_sampler.py        # 采集/入库速率采样与趋势数据
│   │   ├── system_manage.py       # 用户、角色、菜单、权限管理逻辑
│   │   ├── task_manager.py        # 后台任务、导出任务管理
│   │   └── ws_push.py             # 实时推送订阅、快照、心跳处理
│   ├── tests              # 后端单元测试
│   │   └── test_task_manager.py   # 任务管理器测试
│   ├── __init__.py
│   └── main.py            # 后端 ASGI 应用入口
├── exports                # 历史数据导出文件目录
├── logs                   # 后端运行日志目录
├── .dockerignore          # 后端 Docker 构建忽略规则
├── .env.example           # 后端环境变量示例
├── Dockerfile             # 后端 Docker 镜像构建文件
├── main.py                # 后端启动兼容入口
├── README.md              # 后端说明文档
└── requirements.txt       # 后端 Python 依赖列表
```

