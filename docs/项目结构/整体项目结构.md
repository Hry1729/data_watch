# 整体项目结构

> 说明：本文用于快速理解仓库顶层目录职责。前端 Vue 项目已有独立结构文档，本文只做入口说明，不重复展开。

```text
data_watch
├── .antigravitycli          # Antigravity CLI 本地配置/缓存目录
├── .claude                  # Claude 本地配置目录
├── .git                     # Git 版本控制目录
├── .github                  # GitHub 工作流、仓库配置目录
├── .pytest_cache            # pytest 运行缓存目录
├── .specify                 # 规格/需求辅助工具目录
├── .uv-cache                # uv / Python 包管理缓存目录
├── .vite                    # Vite 本地缓存目录
├── agent                    # Data Watch Agent，本机进程管理、配置引导和日志 tail 服务
├── app                      # Data Watch Console 桌面应用（Tauri + React）
├── backend                  # 后端 HTTP / WebSocket API 服务
├── collector                # 数据采集模块，负责设备读取、实时缓存和入库 Stream 写入
├── data                     # 原始点位、故障、OPC/PLC 相关资料与导入数据
├── deploy                   # Docker Compose、镜像包、Nginx 与部署环境配置
├── dist                     # 顶层构建产物目录
├── docs                     # 项目设计、接口、运维、联调和结构文档
├── frontend                 # Web 前端项目（结构详见 docs/前端/art design pro/项目结构.md）
├── scripts                  # 数据库迁移、TDengine/Redis 初始化等辅助脚本
├── writer                   # 入库模块，消费 Redis Stream 并批量写入 TDengine
├── .dockerignore            # Docker 构建忽略规则
├── .gitignore               # Git 忽略规则
├── AGENTS.md                # 本仓库 Agent 协作规则
├── CLAUDE.md                # Claude 使用说明/约束
├── CODEX.md                 # Codex 使用说明/约束
├── claude                   # Claude 相关占位文件
├── start-dev.bat            # Windows 批处理启动入口
├── start-dev.cmd            # Windows CMD 启动入口
└── start-dev.ps1            # PowerShell 开发环境启动脚本
```

## 核心模块关系

```text
frontend                  # Web 前端
app                       # 桌面控制台
agent                     # 本机 Agent，供 app 管理 collector/writer
backend                   # 业务 API、实时推送、历史查询
collector                 # 采集设备数据 -> Redis latest/window/stream
writer                    # Redis Stream -> TDengine
deploy                    # 容器化部署
scripts                   # 初始化与迁移脚本
data                      # 原始业务资料
docs                      # 文档中心
```

## 不展开目录说明

```text
.git                      # Git 内部目录，不作为业务结构展开
.pytest_cache             # 测试缓存，可删除重建
.uv-cache                 # Python 依赖缓存，可删除重建
.vite                     # Vite 缓存，可删除重建
dist                      # 构建输出目录，不作为源码维护
frontend/node_modules     # 前端依赖目录，详见前端项目自身文档
app/node_modules          # app 前端依赖目录，按依赖处理，不展开
app/src-tauri/target      # Tauri/Rust 构建产物，按构建输出处理
backend/.py314t-site      # 后端本地 Python 依赖目录，按依赖处理
backend/.pip-temp         # pip 临时目录，按临时缓存处理
collector/.venv-pack      # collector 打包用虚拟环境，按依赖处理
collector/build           # collector PyInstaller 构建中间产物
collector/dist            # collector 可执行文件构建产物
writer/.venv-pack         # writer 打包用虚拟环境，按依赖处理
writer/build              # writer PyInstaller 构建中间产物
writer/dist               # writer 可执行文件构建产物
```
