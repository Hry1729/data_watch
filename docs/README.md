# 工业数据采集与监控平台 - 文档中心

> 本目录为自动化码头设备数据采集与监控平台的全部文档汇总，涵盖设计方案、前后端开发、数据库、数据采集模块及第三方技术参考资料。

---

## 目录结构

```
docs/
├── 设计方案/          # 系统整体设计与架构方案
├── 前端/             # 前端开发指南与组件文档
├── 后端/             # 后端开发与策略文档
├── 前后端联调/        # 前后端协作治理与联调规范

├── 采集模块/          # 数据采集方案与代码审查

├── 架构图.png        # 系统架构图
└── README.md         # 本文件
```

## 技术栈速览

| 层级 | 技术 |
|------|------|
| 数据采集 | OPC DA 协议、异步采集服务 |
| 时序存储 | TDengine 3.0+ |
| 配置存储 | MySQL 8.0+ |
| 后端服务 | TurboAPI (Python) |
| 前端展示 | Vue 3 + TypeScript + Element Plus (ArtDesignPro) |
| 数据可视化 | Perspective |
| 实时通信 | WebSocket |

## 新人阅读建议

1. **先读概要设计**：`设计方案/概要设计说明书v2.md` — 建立项目全貌
2. **再看数据库设计**：`数据库/数据库结构v3.md` — 理解数据模型
3. **按角色深入**：
   - 前端开发：`前端/开发必读文档.md` → `前端/ArtDesignPro项目结构.md`
   - 后端开发：`设计方案/标准后端架构.md` → `后端/` 目录
   - 联调对接：`前后端联调/README.md` → 按 01-13 顺序阅读
   - 采集开发：`采集模块/OPC_DA_中心采集实施计划.md` → 相关审查报告
