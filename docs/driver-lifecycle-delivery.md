# DataWatch 驱动包化交付记录

本次完成 P2/P3 的代码与冻结产物：五种官方驱动统一为独立包，Collector 仅加载数据目录中的激活包；首次预装、官方包卸载/恢复、目标运行时预检、冷切换、升级失败回滚和崩溃恢复均已接入。

## 已完成的行为

- S7、GE 的地址解析、读块规划与解码迁入包内，保留原算法和回归样例；OPC DA 的 IPC 客户端与协议定义也迁入包内。
- Agent/Collector 共用静态清单校验。原生依赖在目标 cp314t 运行时验证；包括传递依赖的冲突检查，不再删除其他包已经加载的模块。
- 新增 Ed25519 独立包签名、完整文件清单和 `packaging/sign-driver.py` 签包工具；可信公钥由发行管理员配置，上传者不能自行设置信任。代码篡改、额外文件、冒充发布者、未知密钥、伪造签名和夹带字节码均在导入前拒绝。
- 普通用户可查看，管理员才能变更。页面先预检，再显示名称、版本与影响范围供确认。
- 正在运行时，先停进程再切换，恢复后核验 PID、启动身份、包版本与摘要。原本停止时保持停止。
- 首次预装完成后不覆盖用户版本、不自动装回被卸载的官方包。损坏或缺失的官方包支持显式修复。
- 卸载检查设备引用，边缘节点同时检查本地配置；保留全局协议目录、设备、点位映射和历史数据。
- 节点安装记录带本机节点身份。分布式中心显示“本机不适用”，不把本机状态当成边缘状态。
- 未完成事务阻止新的包变更及手动采集启停，避免中断请求绕过恢复流程。

## 验证结果

- Agent 最终全套回归：253 通过、1 跳过，包含签名、普通用户只读、角色限制与未完成事务门禁。
- Collector 全套回归：518 通过、4 跳过、1 失败。失败为本次未修改的 `test_thread_pool_rejects_submit_beyond_capacity`；单独复验仍失败。其 `Future.result()` 返回与释放容量的完成回调存在时序差异，未在驱动包化任务中改动线程池代码。
- 包契约和注册表专项：最终 50 项通过，含固定 OPC DA 代理版本、传递依赖冲突、已加载模块不被替换。
- Backend 生命周期回归：30 项通过，含停止状态注册和官方卸载保留全局协议目录。
- 前端状态：10 项通过；TypeScript 检查和 Vite 生产构建通过。
- Agent、中心 Collector、边缘 Collector 三种 EXE 均已构建。中心与边缘均通过真实 Agent HTTP 首次预装、预检、卸载、Agent 重启保留卸载选择、恢复安装验收；同时覆盖普通用户只读限制，以及测试发布者签名第三方包的预检和安装。
- 安装器的升级失败、旧包恢复、原先停止时的崩溃恢复使用真实 Collector EXE 做导入预检，进程故障与探针故障由测试注入。现场 PLC、OPC 服务器未连接测试。
