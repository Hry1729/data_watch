# 前端契约映射清单

> 更新时间：2026-04-13
> 作用：建立“页面 -> 接口 -> 关键字段 -> 空态/错误态”的明确映射

---

## 一、使用规则

1. 本清单只描述联调映射关系，不替代 `docs/后端/API接口文档.md`
2. 所有字段名、默认值、错误语义以 API 文档为准
3. 前端页面、类型定义、状态管理应从本清单和 API 文档共同派生

---

## 二、路由基线说明

当前设备监控模块采用统一路由前缀：

```text
/device-monitor/*
```

其中实时监控页面的规范路由为：

```text
/device-monitor/realtime
```

说明：

- 旧文档中的 `/monitor` 视为历史表述
- 联调、路由注册、菜单配置和验收口径统一使用 `/realtime`

---

## 三、页面映射清单

| 页面 | 规范路由 | 主要接口 | 关键字段 | 必须稳定的契约点 | 空态 / 错误态 |
|------|----------|----------|----------|------------------|---------------|

## 四、页面与字段稳定级别

| 级别 | 说明 | 示例 |
|------|------|------|
| S0 | 本轮冻结，不允许结构性变更 | `BaseResponse`、分页语义、历史查询主结构 |
| S1 | 本轮尽量稳定，仅允许说明性补充 | Dashboard 聚合统计字段 |
| S2 | 可在签收后补充字段，但不得影响现有页面 | 备注字段、调试字段、附加统计字段 |

---

## 五、最小闭环映射

最小闭环只聚焦以下页面与接口：

| 能力 | 页面 | 接口 |
|------|------|------|
| 设备树 | 实时监控 | `GET /api/device-monitor/monitor/device-tree` |
| 实时初始化 | 实时监控 | `GET /api/device-monitor/monitor/realtime-init` |
| 实时推送 | 实时监控 | `WS /api/device-monitor/ws/realtime-push` |
| 设备列表 | 设备管理 | `GET /api/device-monitor/device/list` |

说明：

- 在最小闭环完成前，历史查询、Dashboard 高级统计、导入导出都不作为首轮阻塞项

---

## 六、字段核对方式

联调前核对字段时，按以下顺序检查：

1. 接口路径是否一致
2. 请求参数名是否一致
3. 分页字段是否一致
4. 时间字段格式是否一致
5. 空数据结构是否一致
6. 403 / 500 错误处理是否一致
7. WebSocket 事件类型是否一致
