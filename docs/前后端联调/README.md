# 前后端联调治理索引

> 更新时间：2026-05-18
> 适用范围：`/device-monitor` 业务域前后端联调治理

---

## 一、目录目的

本目录用于沉淀前后端联调期间的共享治理文档，解决以下问题：

1. API / WebSocket 契约漂移
2. 前端设计风格与 ArtDesignPro / `frontend/DESIGN.md` 不一致
3. 路由、菜单、页面、权限注册不一致
4. 实时态 / 历史态语义不一致
5. 联调环境、真实服务链路、Fake Data、验收口径不清
6. 登录恢复后，页面数据缺口没有统一跟踪入口

---

## 三、使用顺序

建议按以下顺序使用本目录文档：

1. 先阅读 `01-v1接口契约冻结与变更门禁.md`
2. 再阅读 `02-前端契约映射清单.md`
3. 然后按职责分别使用：
   - 前端：`03-前端设计适配规则.md`、`04-路由菜单页面权限矩阵.md`
   - 后端 / 数据库 / 采集：`05-Redis实时态与告警态语义说明.md`
   - 测试 / 协调：`06-联调环境矩阵与验收口径.md`
   - 执行准备：`08-首批测试假数据落库清单.md`、`09-首批测试假数据执行说明.md`
   - 登录与权限：`10-真实数据登录与权限联调说明.md`
   - 页面缺口推进：`11-真实数据页面缺口与接口联调TODO.md`
   - 系统管理实接：`13-用户角色和菜单实接后端与数据库方案.md`
4. 进入执行阶段前，统一阅读 `07-最小闭环优先执行说明.md`
