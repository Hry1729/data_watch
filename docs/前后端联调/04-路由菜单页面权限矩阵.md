# 路由菜单页面权限矩阵

> 更新时间：2026-04-13
> 作用：固定设备监控模块的路由、菜单、页面目录与权限语义

---

## 一、基线说明

当前设备监控模块的规范前缀为：

```text
/device-monitor
```

规范页面范围：

- Dashboard
- Driver
- Device
- Point
- Realtime
- History
- Log

说明：

- `docs/前端/页面设计文档.md` 中旧写法 `/monitor` 视为历史表述
- 当前规范页面路径统一使用 `/device-monitor/realtime`

## 三、使用规则

1. 路由路径、页面目录、菜单标题 Key 三者必须一一对应
2. 页面一旦进入联调，不允许随意改 path
3. 若后端菜单接口采用 backend 模式返回菜单，必须保持与本矩阵语义等价
4. 若前端使用 async routes，本矩阵中的权限语义仍必须在菜单数据中体现

---

## 四、权限语义说明

### 4.1 页面访问权限

页面访问权限用于控制整个页面是否可见，例如：

- `device_monitor:device:view`
- `device_monitor:history:view`

### 4.2 操作权限

操作权限用于控制按钮、导入导出、删除等行为，例如：

- `device_monitor:device:create`
- `device_monitor:point:delete`
- `device_monitor:history:export`

---

## 五、联调核对项

联调前必须核对以下内容：

- 菜单标题 Key 是否与页面职责一致
- 页面目录是否与路由 path 一致
- 后端菜单接口是否返回等价权限语义
- 权限不足时是否展示空态而非页面报错
- Realtime 页是否统一使用 `/device-monitor/realtime`
