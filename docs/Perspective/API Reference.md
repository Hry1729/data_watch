# API Reference

Perspective's complete API documentation is hosted on `docs.rs`.

---

## Python API

- `perspective` — Core library
- `perspective.widget` — JupyterLab widget
- `perspective.handlers.aiohttp` — AIOHTTP handler
- `perspective.handlers.starlette` — Starlette/FastAPI handler
- `perspective.handlers.tornado` — Tornado handler
- `perspective.virtual_servers.clickhouse` — ClickHouse virtual server
- `perspective.virtual_servers.duckdb` — DuckDB virtual server

---

## JavaScript API

- `@perspective-dev/client` (Browser) — Browser client
- `@perspective-dev/client` (Node.js) — Node.js client
- `@perspective-dev/client Clickhouse Virtual Server` — ClickHouse virtual server
- `@perspective-dev/client DuckDB Virtual Server` — DuckDB virtual server
- `@perspective-dev/viewer` — Web Component
- `@perspective-dev/react` — React components

---

## Rust API

- `perspective` — Core library
- `perspective-client` — Client library
- `perspective-server` — Server library
- `perspective-python` — Python bindings
- `perspective-js` — JavaScript bindings
- `perspective-viewer` — Web Component
