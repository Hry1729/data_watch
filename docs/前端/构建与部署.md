# 构建与部署

## 构建

项目开发完成之后，在项目根目录下执行以下命令进行构建：

bash

```
pnpm build
```

构建打包成功之后，会在根目录生成对应的应用下的 dist 文件夹，里面就是构建打包好的文件

## 浏览器兼容要求

本项目前端使用 Tailwind CSS v4 和较新的 CSS 特性，例如 `oklch()`、`color-mix()`、`rgb(from ...)`、媒体查询范围语法等。目标电脑即使静态资源请求全部返回 200，如果浏览器内核太旧，也会出现登录页排版混乱、顶部栏/侧边栏错位、登录后页面空白等问题。

正式部署和现场验收时，浏览器要求如下：

```text
Chrome / Chromium / Edge Chromium 内核 >= 111
Firefox >= 128
Safari >= 16.4
```

不支持：

```text
IE 模式
兼容模式
旧版 360 / 搜狗 / QQ 浏览器内核
低版本企业内置浏览器
```

如果必须使用国产浏览器，需要切换到“极速模式”，并在浏览器版本页面确认实际 Chromium 内核版本。可在目标电脑地址栏打开：

```text
chrome://version
edge://version
```

若登录页本身已经排版异常，优先检查浏览器内核版本，不要先排查后端权限或菜单数据。Tailwind CSS v4 官方兼容说明见：[Tailwind CSS Compatibility](https://tailwindcss.com/docs/compatibility)。

## 部署

部署时可能会发现资源路径不对，只需要修改.env.production 文件即可。

bash

```
# 根据自己存放的静态资源路径来更改配置
VITE_BASE_URL = /art-design-pro/
```

## 部署到非根目录

需要更改 .env.production 配置，把 VITE_BASE_URL 改成你存放项目的路径，比如:

bash

```
VITE_BASE_URL = /art-design-pro/
```

然后在 nginx 配置文件中配置

bash

```
server {
  location /art-design-pro {
    alias  /usr/local/nginx/html/art-design-pro;
    index index.html index.htm;
  }
}
```
