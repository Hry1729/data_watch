# 登录页深色科技风改版方案

> 状态：已评审通过（含 Codex 审查修正）｜日期：2026-06-03
> 范围：登录 / 注册 / 忘记密码 三页统一改版
> 关联：本方案仅含视觉改版；登录逻辑与路由后续缺陷修复另见 `docs/前端/登录与路由缺陷修复-2026-06-03.md`

## 一、目标

将授权类页面从「浅色玻璃卡片 + 几何装饰」改为「深色科技风：全屏粒子连线星空 + 底部流光波浪 + 深色玻璃登录卡」。
暗色为主（严格对齐设计图），浅色模式基于同一布局重新调色。

## 二、设计决策（已确认）

| 项 | 决定 |
|----|------|
| 背景特效 | 轻量 canvas 自绘（粒子连线 + 底部波浪），**不引第三方库** |
| 顶部导航（产品特性/解决方案/帮助中心） | **不做**（删除该元素，原页面本无此项） |
| 第三方登录图标（电话/邮箱/盾牌） | **不做** |
| 左侧特性卡片（实时采集/可视监控/稳定可靠） | **不做**，左侧仅保留标题 + 副标题 |
| 拖拽滑块验证 | **保留**，补深色卡片下的暗色适配 |
| 账号输入 | **保留**现有「可搜索下拉 + 历史账号 + 游客一键登录」 |
| 浅色模式 | 暗色为主 + 适配浅色 |
| 改版范围 | 登录 / 注册 / 忘密 三页统一 |

## 三、架构思路

采用「共享层重塑」：不重写三页，改造三页共享的 `LoginLeftView`、`style.css`，新增一个背景组件，三页自动继承同款风格。

```
现在： [左 65vw 品牌区(几何装饰+插画)] | [右面板(浅色渐变) + 玻璃卡片]
                 ↓
改后： [全屏深色科技背景(canvas 粒子连线 + 底部流光波浪)]
        上层：左侧大标题/副标题 · 右上角工具栏 · 右侧深色玻璃登录卡
```

## 四、关键修正（Codex 审查）

1. **三页作用范围**：右侧容器只有登录页带 `auth-right-panel`，注册/忘密页是裸 `relative flex-1`。
   → 将 `.auth-right-panel` 重定义为三页通用「右栏容器」类（`position:relative; z-index:1`），**注册页、忘密页右侧容器各补该类名（1 行）**，删除旧的浅色渐变 + `::before` 光斑。
2. **背景层级 / 移动端**：`AuthBackground` 根 canvas 必须 `position:fixed; inset:0; z-index:0; pointer-events:none;`；上层显式抬高（右栏 `z-index:1`、顶栏 `z-10`）。保证背景铺满、不挡输入、移动端仍显示。
3. **滑块暗色适配**：现 `textColor="var(--art-gray-700)"` 在深色卡上偏暗。
   → 滑块 `textColor / background / progressBarBg / handlerBg` 按 `isDark` 给深色卡专用取值（亮色文本 + 深轨道 + 主题色进度条）。
4. **固定高度裁切**：`.auth-right-wrap` 现为 `w-[440px] h-[650px] overflow-hidden` + 绝对居中；注册页字段多、忘密页布局不同，易被裁。
   → 去掉固定 `h-[650px]` 与 `overflow-hidden`，改 `min-height` + flex 居中，三页 × 移动端实测不裁切。

## 六、背景组件实现要点（AuthBackground.vue）

- **底色**：暗色深蓝径向渐变（约 `#0a0e1a → #0d1424`）；浅色亮蓝渐变（约 `#f0f5ff → #e6eeff`）。
- **粒子网络**：节点缓慢漂移，邻近节点（距离阈值内）连线，线/点透明度随距离衰减；暗色青蓝、浅色柔和蓝。
- **底部波浪**：2~3 层正弦波路径，蓝→透明竖向渐变填充，缓慢相位移动。
- **性能 / 健壮性**：`requestAnimationFrame` 单循环；粒子数按视口面积计算并封顶；`devicePixelRatio` 高清绘制；`resize` 重算；`onBeforeUnmount` 取消动画与监听；`prefers-reduced-motion` 下弱化或静态帧。

## 七、验收口径

登录 / 注册 / 忘密 三页 × 暗 / 浅两主题 × 桌面 / 移动端：

- 背景铺满整屏、不遮挡输入与按钮；
- 玻璃卡片在各页字段数量下均不被裁切；
- 滑块文字在深色卡上清晰可读；
- 主题切换、语言切换、账号历史 / 游客一键登录、滑块验证等现有功能不回退。
