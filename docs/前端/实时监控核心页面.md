# 页面设计理念

该页面定位为 **自动化码头设备实时点位监控页面**，不是传统数据报表页，而是面向工程技术人员、设备抢修人员和中控运维人员的 **实时诊断型监控界面**。

页面核心目标是：

1. **快速选择设备与监控点位**
    用户通过上方工具栏确认当前设备和已订阅点位，明确当前正在监控哪些变量。
2. **突出实时趋势变化**
    中间大面积区域只保留一张核心趋势图，弱化其他干扰信息，让用户可以第一时间观察点位变化、异常波动、状态切换。
3. **右侧集中展示当前值**
    右侧为统一卡片容器，内部包含多个小卡片，每个小卡片对应一个点位。这样即使未选择点位，也可以保留一个完整的模块结构，避免页面右侧空荡。
4. **底部展示系统运行状态**
    底部状态条用于展示采集服务、TDengine、Perspective、最后同步时间等系统状态，便于判断是设备异常还是系统链路异常。
5. **整体风格参考 ArtDesignPro**
    使用干净的后台系统视觉风格，白底、浅灰背景、圆角卡片、轻阴影、蓝色主色调，强调专业、现代、清爽、可落地。

# 页面结构说明

## 1. 顶部控制栏

```
当前设备：QC100
监控点位：多个彩色标签
操作按钮：开始监控 / 停止监控 / 清空选择 / 导出
连接状态：WebSocket已连接
刷新频率：1秒
```

设计要点：

- 当前设备编号要突出显示，使用蓝色加粗。
- 监控点位使用彩色标签，每个标签有关闭按钮。
- 开始监控使用主色蓝色按钮。
- 停止监控使用红色危险按钮。
- WebSocket 状态使用绿色圆点 + 浅绿色背景。
- 刷新频率放在右侧，做成下拉选择。

------

## 2. 中央趋势图区域

```
标题：点位实时趋势
图表类型切换：折线图 / 柱状图 / 透视分析
图表操作：全屏 / 设置 / 更多
图表主体：多条实时趋势线
```

设计要点：

- 趋势图是页面视觉中心，占据最大面积。
- 支持多条曲线同时展示。
- 数值类点位使用左 Y 轴。
- 状态类点位可以使用右 Y 轴。
- 图例放在图表上方居中。
- 图表区域留白充分，网格线淡化，曲线颜色清晰。
- 折线图按钮处于选中状态，使用蓝色背景。

------

## 3. 右侧实时点位卡片容器

```
外层卡片标题：实时监测点
内部多个小卡片：
  第一行：点位名称
  第二行：变量地址 / 点位标识，小字浅色
  第三行：实时值，大字号高亮
```

设计要点：

- 右侧必须是一个完整的大卡片容器，不要直接堆叠小卡片。

- 大卡片内部用多个小卡片展示点位。

- 每个小卡片视觉结构统一。

- 点位名称使用深色中等字重。

- 变量地址使用小号浅灰蓝色文本。

- 实时值使用大字号，按类型使用不同颜色：

  - 高度：蓝色
  - 位置：绿色
  - 电流：橙色
  - 状态：紫色

- 小卡片可以带轻微背景渐变和柔和阴影。

- 如果没有订阅点位，大卡片内显示空状态：

  ```
  暂未选择监控点位
  请从上方选择需要监控的变量
  ```

------

## 4. 底部状态栏

```
采集服务运行正常
TDengine 已连接
Perspective 绘图更新正常
最后同步时间
```

设计要点：

- 底部做成一整条横向状态卡片。
- 每个状态项之间用竖线分隔。
- 使用绿色图标表示正常。
- 最后同步时间放在最右侧。
- 该区域高度不要太高，作为辅助信息存在。

# 空状态设计补充

右侧实时监测点卡片在没有监控点位时，建议显示：

```
┌──────────────────────────────┐
│ 实时监测点                    │
│                              │
│        暂未选择监控点位        │
│   请从上方选择需要监控的变量    │
│                              │
│        [ 添加监控点位 ]        │
└──────────────────────────────┘
```

空状态提示词：

```
当没有选择任何监控点位时，右侧实时监测点大卡片内部不要空白，显示居中的空状态插画或线性图标，文字为“暂未选择监控点位”，副标
```
