# 业务理解

- 软件名称：工业设备数据采集与监控平台
- 产品定位：面向工业自动化现场的设备数据采集、运行监控与数据管理平台。系统以PLC及其他工业数据源为主要接入对象，码头是当前项目的典型应用场所之一，但产品能力不限定于码头，可用于制造、物流、能源和基础设施等存在工业设备采集需求的场景。
- 面向领域 / 行业：工业自动化与工业物联网领域
- 核心价值：统一管理工业设备、通信驱动和采集点位，持续获取现场数据并提供实时监控、历史分析、运行告警和采集链路运维能力，减少不同PLC及工业协议接入时的重复建设。
- 证据文件：`业务理解证据.md`

## 目标用户

- 工业企业设备管理人员
- 自动化工程师和PLC工程师
- 生产运行监控人员
- 工业信息化系统管理员
- 设备运维与故障排查人员

## 主要业务功能

- 工业协议与驱动管理
- 设备与点位配置
- 工业数据采集
- 实时状态监控
- 历史数据查询与导出
- 采集与入库运行监控
- 系统日志与告警追踪
- 协议驱动扩展

## 功能说明

- 工业协议与驱动管理：集中查看驱动名称、协议说明、读写能力、可用状态和更新时间。项目已实现S7、GE SRTP、OPC UA及OPC DA相关接入路径，并将其他协议保留为后续扩展能力。
- 设备与点位配置：按设备类型和分组维护设备编号、名称、关联驱动、启停状态、通信状态及数据质量；为设备配置IO地址、数据类型、采集周期、存储标志等点位信息，并支持表格导入导出。
- 工业数据采集：采集服务依据数据库中的设备、协议和点位配置建立任务，执行批量读取、连接健康检查、自动重连和异常恢复，将实时数据送入缓冲与后续存储链路。
- 实时状态监控：用户可选择设备和监控点位，查看数值型及布尔型点位的实时值、质量和趋势，并可调整刷新频率、暂停监控、清空记录和导出结果。
- 历史数据查询与导出：按设备、点位、时间范围、聚合粒度和聚合方式查询历史数据，通过折线图、面积图、柱状图、散点图及数据矩阵查看结果，并导出CSV文件。
- 采集与入库运行监控：桌面运维控制台显示Collector与Writer的运行状态、CPU和内存、采集或入库速率、任务列表、趋势及实时日志，并提供启动、停止和重启操作。
- 系统日志与告警追踪：展示系统、认证、操作、采集、存储等来源的日志和告警，支持按级别、时间和来源查询，帮助用户定位设备离线、采集失败和入库异常。
- 协议驱动扩展：采集端以统一BaseDriver接口约束连接、断开、批量读写、健康检查和重连行为，并由设备管理器按协议创建具体驱动。新增协议可沿用该接口增加驱动实现并接入协议映射，避免改变上层设备、点位和调度流程。

## 典型操作流程

1. 管理员完成系统连接配置并确认MySQL、Redis、TDengine等支撑服务可用
2. 在驱动管理中确认现场设备所需协议驱动及其可用状态
3. 在设备管理中新增或导入工业设备，填写设备标识、类型、关联驱动和连接信息
4. 在点位管理中为设备新增或导入采集点位，配置IO地址、数据类型、采集周期和存储属性
5. 启动Collector采集模块和Writer入库模块，观察模块状态、速率、任务及日志
6. 在实时监控中选择设备和点位，查看当前值、数据质量及变化趋势
7. 在历史数据中按时间范围查询、对比并导出已存储的设备数据
8. 出现离线、异常或告警时，通过总览、设备状态和系统日志定位问题并调整配置

## 操作手册页面/流程模块

1. 用户登录：用户打开平台登录地址，或启动Data Watch Console后停留在登录页面；尚未完成身份验证时，受保护页面不会直接显示。
   - 使用场景：值班人员、自动化工程师或系统管理员首次打开平台、登录状态失效，或者退出后重新进入受保护页面时使用。Web管理端可从历史用户名或游客账号中选择，也可手工输入账号；桌面控制台用于进入采集与入库运维功能。
   - 操作要点：先在用户名区域选择历史账号、游客账号或手工输入管理员分配的用户名；输入密码并完成页面要求的滑块验证；确认用户名和密码均已填写后点击登录按钮；按钮显示登录中时等待身份验证完成，不重复提交
2. 设备数据总览：登录后从设备监控菜单进入工作台或总览页面。
   - 使用场景：值班人员进入系统后快速判断工业现场设备和采集链路的整体运行状态。
   - 操作要点：查看顶部指标卡确认设备在线和告警情况；切换趋势时间范围并点击刷新；从设备类型分布进入设备列表，或从最近报警进入日志页面
3. 协议驱动管理：用户登录Web管理端后，从设备监控菜单进入驱动管理页面；通常在新增设备、调整设备协议或排查通信问题之前打开。
   - 使用场景：自动化工程师新增PLC、边缘采集设备或其他工业数据源前，先在此核对现场协议是否已有可用驱动；设备通信异常时也可回来检查驱动状态和读写能力。平台采用可扩展的协议接入方式，新增协议驱动登记后可继续在同一页面统一查看。
   - 操作要点：先查看驱动总数和可用比例，判断当前协议接入能力是否正常；在搜索框输入驱动名称或协议描述，缩小待核对范围；查看目标驱动的协议类别和描述，确认它与现场PLC或数据源协议匹配；核对读写类型，确认当前业务仅需读取还是还涉及写入
4. 设备管理：从设备监控菜单进入设备管理。
   - 使用场景：管理员接入新PLC或其他工业设备、修改设备配置、停用设备或批量整理现场设备清单时使用。
   - 操作要点：在设备树选择全部设备、设备类型或具体分组；使用关键字和状态条件筛选设备；点击新增设备填写必填信息并选择关联驱动；保存后查看设备状态，必要时进入点位页面继续配置
5. 采集点位管理：从设备监控菜单进入点位管理，或在设备列表点击某台设备的点位按钮。
   - 使用场景：PLC工程师根据控制器变量表或现场测点表建立、修改或批量导入采集点位。
   - 操作要点：在设备树中选择目标设备；点击新增点位并填写点位序号、名称、IO地址、数据类型、驱动、采集周期和存储属性；保存后查看点位详情与当前值；批量配置时下载模板、填写后导入，或从已有设备类型模板补充点位
6. 实时数据监控：从设备监控菜单进入实时监控。
   - 使用场景：运行人员观察生产设备状态、核对PLC信号变化或临时跟踪异常点位时使用。
   - 操作要点：选择设备并勾选需要观察的点位；确认选择后开始接收实时数据；根据需要调整刷新率和布尔型变量独立图表设置；查看当前值、质量状态和趋势，必要时暂停或清空记录
7. 历史数据查询与导出：从设备监控菜单进入历史数据。
   - 使用场景：工程师复盘设备运行、分析异常前后数据、核对生产过程或形成数据报表时使用。
   - 操作要点：选择设备并勾选一个或多个查询点位；设置时间范围、聚合粒度和聚合方式；点击查询并在趋势图和数据矩阵中查看结果；切换图表类型或加载更多明细
8. 采集与入库模块运维：启动Data Watch Console并登录，从总览进入Collector或Writer详情页。
   - 使用场景：系统管理员部署后启动数据链路、日常巡检采集与入库状态，或在模块异常时进行恢复。
   - 操作要点：在总览确认两个模块的当前状态和连接健康；点击模块进入详情，查看运行指标、任务列表、趋势和日志；模块未运行时执行启动，异常时根据日志确认影响后执行重启；停止或重启前阅读确认对话框中的采集中断或入库中断提示
9. 系统连接与运行参数设置：在Data Watch Console中进入设置页面。
   - 使用场景：管理员首次部署、迁移服务器、修改数据库地址或调整采集运行参数时使用。
   - 操作要点：进入数据库标签填写或核对各服务连接信息；分别点击测试连接并确认状态；按需修改Collector、Writer路径或运行参数；点击保存，或选择保存并重启对应模块使配置生效
10. 系统日志与告警查询：从设备监控菜单进入系统日志或日志终端，也可从总览的最近系统报警进入。
   - 使用场景：设备离线、点位不更新、采集失败、入库积压或用户操作异常时，运维人员追查发生时间和原因。
   - 操作要点：根据异常发生时间选择查询范围；按级别、来源或关键字缩小日志范围；查看日志内容并结合设备或模块状态判断问题位置；处理后刷新页面确认是否仍产生同类异常

## 申请表建议口径

- 开发目的：建设可扩展的工业设备数据采集与监控平台，统一接入PLC等工业数据源并支撑实时监视、历史分析和运行维护。
- 软件的主要功能：本软件面向工业自动化和工业物联网场景，提供从通信驱动、设备及采集点位配置，到实时采集、缓存、时序入库、状态监控和历史分析的完整业务链路。管理员可在驱动管理中查看协议驱动的名称、说明、读写类型和可用状态；在设备管理中按类型或分组维护设备编号、设备名称、关联驱动、启停状态、连接状态与数据质量，并通过Excel完成批量导入和导出；在点位管理中配置点位序号、名称、IO地址、数据类型、采集周期、只读属性和存储标志。运行过程中，采集服务根据数据库配置建立设备连接和采集任务，对PLC及其他工业数据源执行批量读取、健康检查、重连和异常恢复，将最新值、窗口数据和待入库数据写入Redis，再由Writer批量写入TDengine。用户可在工作台查看设备总数、在线率、采集点位、告警、设备通信和类型分布；在实时监控中选择设备与点位，查看当前值、数据质量及数值型或布尔型趋势，暂停或恢复监控并导出数据；在历史数据页面按设备、点位、时间范围、聚合粒度和聚合方式查询，通过多种图表和数据矩阵分析结果并导出。桌面运维控制台还提供Collector与Writer的启动、停止、重启、运行指标、任务状态、趋势和实时日志查看，并支持数据库连接测试及运行参数保存。系统以统一驱动接口组织协议实现，现有接入覆盖S7、GE SRTP、OPC UA和OPC DA相关模式，可通过新增驱动实现及协议映射继续扩展其他工业通信协议。
- 技术特点：异步并发采集、统一驱动接口、多协议扩展、Redis缓冲、TDengine时序存储、WebSocket实时推送、采集与入库进程分离。
- 软件的技术特点选项：物联网软件
- 软件分类：应用软件
