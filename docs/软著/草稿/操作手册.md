## 二、说明

工业设备数据采集与监控平台 V1.0适用于工业自动化与工业物联网领域场景。用户进入系统后，可以围绕实际工作内容完成账号进入、业务创建、过程查看、结果确认和资料管理等操作。

日常使用时，工业企业设备管理人员、自动化工程师和 PLC 工程师、生产运行监控人员、工业信息化系统管理员可以按照页面提示从入口进入相应页面，查看当前业务状态，并根据页面中的按钮、输入框、列表或弹窗继续处理。统一管理工业设备、通信驱动和采集点位，持续获取现场数据并提供实时监控、历史分析、运行告警和采集链路运维能力，减少不同 PLC 及工业协议接入时的重复建设。

面向工业自动化现场的设备数据采集、运行监控与数据管理平台。系统以 PLC 及其他工业数据源为主要接入对象，码头是当前项目的典型应用场所之一，但产品能力不限定于码头，可用于制造、物流、能源和基础设施等存在工业设备采集需求的场景。

系统以设备、协议驱动和采集点位为基础资料，采集现场数据后提供实时监控、历史查询和运行告警。

码头设备是当前项目的应用实例之一，系统也可部署在其他使用 PLC 或工业数据源的生产现场。

首次使用应先检查支撑服务连接，再完成驱动、设备和点位配置；日常运行重点关注采集模块、入库模块、实时趋势和系统告警。

当设备离线、数据质量异常或入库积压时，运维人员可结合模块指标、设备状态和日志信息逐级定位。

本手册用于说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按用户能够看到的页面、入口、按钮、输入项、提示信息和处理结果进行说明。

## 三、功能特点

用户可在登录页面验证 Web 管理端和桌面运维控制台用户身份，并根据获准角色进入设备监控、采集运维和系统设置页面。页面上的系统名称和登录提示、用户名输入框、历史账号和游客选项、掩码显示的密码输入框、拖动滑块验证区域和登录按钮及登录中状态会集中呈现当前可操作内容，用户处理完成后可以看到登录成功后显示成功提示并进入设备数据总览或桌面控制台首页、账号或密码不正确时停留在登录页并显示相应错误和系统服务不可达时提示检查网络连接。

在设备数据总览页面中，用户主要处理集中展示设备规模、在线情况、采集点位、系统告警、通信状态和设备类型分布。系统把设备总数和在线率指标卡、采集点位和近24小时告警指标、采集量与告警趋势、设备通讯概览和设备类型分布放在当前操作区域，处理结束后会反馈页面刷新后显示最新统计和趋势和无告警时显示暂无系统报警。

协议驱动管理页面关注的是集中查看平台当前登记的工业通信协议驱动、协议说明、读写能力、可用状态和更新时间，为设备接入选择合适协议，并展示后续协议扩展后的统一管理入口。用户通过驱动总数统计卡、可用比例统计卡、驱动名称或协议描述关键字搜索框、序号、驱动名称和协议类别和驱动描述确认当前状态，并在操作结束后获得输入关键字后列表立即显示匹配的驱动名称和协议描述、统计卡显示当前驱动总数与可用比例和读写类型通过标签区分为读写或只读。

用户可在设备管理页面维护需要采集的工业设备及其类型、编号、名称、关联驱动和运行状态。页面上的设备树和分组搜索、当前范围、在线比例和异常比例、设备关键字、启停状态和实时状态筛选、设备编号、名称、驱动、连接状态、数据质量和更新时间列表和新增、编辑、删除、点位、导入和导出按钮会集中呈现当前可操作内容，用户处理完成后可以看到新增、编辑或删除后显示成功或失败提示、导入完成后显示成功数量、失败数量及失败原因和列表实时显示在线、离线、异常和数据质量状态。

在采集点位管理页面中，用户主要处理为工业设备定义需要采集和存储的数据点及其地址、类型和采集属性。系统把设备树、点位总数和近期更新比例、点位名称或 IO 地址搜索、点位名称、IO地址、数据类型、当前值、描述和更新时间列表和新增、详情、编辑、删除、导入和导出按钮放在当前操作区域，处理结束后会反馈保存或删除后显示操作结果、导入结果列出成功数、失败数和最多十条失败原因和点位列表显示当前值和最近更新时间。

实时数据监控页面关注的是持续查看选定设备点位的当前值、数据质量和变化趋势。用户通过当前设备和已选点位、设备与点位选择对话框、开始、暂停、清空、全屏和导出控制、趋势图、实时值卡片和数据质量状态和刷新频率与图表设置确认当前状态，并在操作结束后获得监控启动后持续更新实时值、趋势和同步时间、导出成功或失败时显示提示和设备或连接异常时显示状态信息。

用户可在历史数据查询与导出页面按设备、点位和时间范围查询已存储数据，进行趋势比较和明细分析。页面上的设备和点位选择器、开始与结束时间、聚合粒度和平均值、最大值、最小值、最新值选项、折线图、面积图、柱状图和散点图切换和历史数据矩阵与加载更多按钮会集中呈现当前可操作内容，用户处理完成后可以看到查询期间显示加载状态、无数据时显示当前范围暂无历史数据和加载失败时显示错误提示。

在采集与入库模块运维页面中，用户主要处理查看 Collector 采集模块和 Writer 入库模块的运行状态、任务、速率、趋势及日志，并执行启停或重启。系统把 Collector 和 Writer 状态卡、启动、停止和重启按钮、CPU、内存、采集或入库速率指标、采集任务或 Stream 消费任务列表和采集写入和 TDengine 入库趋势放在当前操作区域，处理结束后会反馈操作后状态卡更新模块状态、趋势和任务列表按运行数据更新和实时日志显示模块输出，异常时提供定位线索。

## 五、用户登录

用户可在登录页面验证 Web 管理端和桌面运维控制台用户身份，并根据获准角色进入设备监控、采集运维和系统设置页面。用户打开平台登录地址，或启动Data Watch Console后停留在登录页面；尚未完成身份验证时，受保护页面不会直接显示。

值班人员、自动化工程师或系统管理员首次打开平台、登录状态失效，或者退出后重新进入受保护页面时使用。Web管理端可从历史用户名或游客账号中选择，也可手工输入账号；桌面控制台用于进入采集与入库运维功能。

用户在用户登录页面会看到系统名称和登录提示、用户名输入框、历史账号和游客选项、掩码显示的密码输入框、拖动滑块验证区域、登录按钮及登录中状态和用户名或密码错误、网络不可达和未知错误提示等信息，并可依据页面显示继续处理。

使用该功能时，用户先先在用户名区域选择历史账号、游客账号或手工输入管理员分配的用户名，随后输入密码并完成页面要求的滑块验证，接着确认用户名和密码均已填写后点击登录按钮，之后按钮显示登录中时等待身份验证完成，不重复提交，最后登录失败时按页面提示检查账号密码或网络连接，修正后重新登录。

页面会按照用户名和密码均为必填项，任一为空时不能提交、Web管理端要求完成滑块验证后再登录、密码始终以掩码显示，历史记录只保留用户名而不保存密码、登录处理中输入框和按钮暂时不可用和用户登录后只能进入其角色获准的页面等规则限制或提示用户。处理结束后，用户可以看到登录成功后显示成功提示并进入设备数据总览或桌面控制台首页、账号或密码不正确时停留在登录页并显示相应错误、系统服务不可达时提示检查网络连接和未知异常时提示稍后重试，用户可保留当前页面继续处理。

## 六、设备数据总览

设备数据总览页面集中展示设备规模、在线情况、采集点位、系统告警、通信状态和设备类型分布。用户登录后从设备监控菜单进入工作台或总览页面。

值班人员进入系统后快速判断工业现场设备和采集链路的整体运行状态。

该部分提供设备总数和在线率指标卡、采集点位和近24小时告警指标、采集量与告警趋势、设备通讯概览、设备类型分布、最近系统报警列表和刷新、查看设备和查看更多按钮等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先查看顶部指标卡确认设备在线和告警情况，随后切换趋势时间范围并点击刷新，最后从设备类型分布进入设备列表，或从最近报警进入日志页面。

如果不满足无统计数据时页面显示空状态和不同角色按权限查看相应内容等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括页面刷新后显示最新统计和趋势和无告警时显示暂无系统报警。

## 七、协议驱动管理

用户可在协议驱动管理页面集中查看平台当前登记的工业通信协议驱动、协议说明、读写能力、可用状态和更新时间，为设备接入选择合适协议，并展示后续协议扩展后的统一管理入口。用户登录 Web 管理端后，从设备监控菜单进入驱动管理页面；通常在新增设备、调整设备协议或排查通信问题之前打开。

自动化工程师新增PLC、边缘采集设备或其他工业数据源前，先在此核对现场协议是否已有可用驱动；设备通信异常时也可回来检查驱动状态和读写能力。平台采用可扩展的协议接入方式，新增协议驱动登记后可继续在同一页面统一查看。

页面上主要呈现驱动总数统计卡、可用比例统计卡、驱动名称或协议描述关键字搜索框、序号、驱动名称和协议类别、驱动描述、读写或只读类型标签、可用、异常或未使用状态和驱动信息更新日期等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先先查看驱动总数和可用比例，判断当前协议接入能力是否正常，随后在搜索框输入驱动名称或协议描述，缩小待核对范围，接着查看目标驱动的协议类别和描述，确认它与现场 PLC 或数据源协议匹配，之后核对读写类型，确认当前业务仅需读取还是还涉及写入，再检查状态列和更新时间，只有状态可用且能力匹配时才在设备管理中关联该驱动，最后清除搜索关键字后恢复完整列表，继续核对其他协议或新扩展驱动。

操作过程中需要注意设备应关联与现场通信协议一致的驱动、只读驱动不能按读写驱动使用、异常、离线或规划中的驱动不能作为当前可用接入方式、状态为未使用仅表示当前没有设备关联，不代表驱动异常和新增协议扩展完成登记并处于可用状态后，才能用于设备配置。操作完成后，系统会显示输入关键字后列表立即显示匹配的驱动名称和协议描述、统计卡显示当前驱动总数与可用比例、读写类型通过标签区分为读写或只读、状态列显示可用、异常或未使用，便于用户决定是否继续配置设备和没有匹配项时列表显示空结果，清除条件后恢复全部驱动。

## 八、设备管理

用户可在设备管理页面维护需要采集的工业设备及其类型、编号、名称、关联驱动和运行状态。用户可以通过从设备监控菜单进入设备管理。

管理员接入新 PLC 或其他工业设备、修改设备配置、停用设备或批量整理现场设备清单时使用。

用户在设备管理页面会看到设备树和分组搜索、当前范围、在线比例和异常比例、设备关键字、启停状态和实时状态筛选、设备编号、名称、驱动、连接状态、数据质量和更新时间列表和新增、编辑、删除、点位、导入和导出按钮等信息，并可依据页面显示继续处理。

使用该功能时，用户先在设备树选择全部设备、设备类型或具体分组，随后使用关键字和状态条件筛选设备，接着点击新增设备填写必填信息并选择关联驱动，之后保存后查看设备状态，必要时进入点位页面继续配置，最后批量维护时下载模板并导入 xlsx 文件，或导出当前设备列表。

页面会按照导入文件仅支持xlsx、导入必填列包括设备类型、设备编号、设备名称和关联驱动、删除设备前需要二次确认和失败行不影响其他成功导入行等规则限制或提示用户。处理结束后，用户可以看到新增、编辑或删除后显示成功或失败提示、导入完成后显示成功数量、失败数量及失败原因和列表实时显示在线、离线、异常和数据质量状态。

## 九、采集点位管理

用户可在采集点位管理页面为工业设备定义需要采集和存储的数据点及其地址、类型和采集属性。用户可以通过从设备监控菜单进入点位管理，或在设备列表点击某台设备的点位按钮。

PLC工程师根据控制器变量表或现场测点表建立、修改或批量导入采集点位。

该部分提供设备树、点位总数和近期更新比例、点位名称或 IO 地址搜索、点位名称、IO地址、数据类型、当前值、描述和更新时间列表和新增、详情、编辑、删除、导入和导出按钮等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在设备树中选择目标设备，随后点击新增点位并填写点位序号、名称、IO地址、数据类型、驱动、采集周期和存储属性，接着保存后查看点位详情与当前值，最后批量配置时下载模板、填写后导入，或从已有设备类型模板补充点位。

如果不满足导入文件仅支持xlsx、设备编号、点位序号、点位名称、IO地址、数据类型和驱动名称为导入必填列、数据类型支持BOOL、INT、DINT、REAL、STRING、WORD和 DWORD 等页面列示值、从模板导入前必须先选择目标设备和删除点位前需要二次确认等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括保存或删除后显示操作结果、导入结果列出成功数、失败数和最多十条失败原因和点位列表显示当前值和最近更新时间。

## 十、实时数据监控

用户可在实时数据监控页面持续查看选定设备点位的当前值、数据质量和变化趋势。用户可以通过从设备监控菜单进入实时监控。

运行人员观察生产设备状态、核对 PLC 信号变化或临时跟踪异常点位时使用。

页面上主要呈现当前设备和已选点位、设备与点位选择对话框、开始、暂停、清空、全屏和导出控制、趋势图、实时值卡片和数据质量状态、刷新频率与图表设置和连接状态和最后同步时间等内容，这些内容用于帮助用户确认当前位置和可执行操作。

## 十六、常见问题解答

问题：设备显示离线或异常怎么办？
解决方法：先在设备管理中确认设备已启用且关联驱动正确，再检查桌面控制台中的 Collector 状态和数据库连接，最后按设备编号、采集来源及异常时间查询系统日志。

问题：实时监控没有数据怎么办？
解决方法：确认已选择设备和点位并启动监控，检查设备连接状态、点位采集周期和数据质量；如果连接中断，可查看 Collector 日志后再决定是否重启。

问题：新增工业协议需要重做设备管理功能吗？
解决方法：不需要重做上层设备和点位管理。新增协议应按统一驱动数据通道实现连接、读写和健康检查，并接入协议创建映射，再经过现场设备验证后投入使用。

问题：修改连接配置后为什么没有立即生效？
解决方法：部分数据库或模块运行参数需要重启 Collector 或Writer。可使用设置页的保存并重启功能，并观察状态和日志确认生效。

问题：历史查询没有结果怎么办？
解决方法：检查设备、点位和时间范围是否正确，确认点位启用了存储，并检查 Writer 运行状态及 TDengine 入库趋势。
