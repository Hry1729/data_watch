## 修复记录

### 2026-05-21：全部 13 项已修复

**writer 模块：**

- **W-C1 已修复**（`mysql_mapper.py`）：`_SQL` 中 `d.device_type_code` 不存在于 `device` 表，新增 `JOIN device_type dt ON dt.id = d.type_id` 并改为 `dt.type_code AS device_type_code`。现场验证 mapper 可正常加载。
- **W-H1 已修复**（`consumer.py`）：`run_loop` 加 `len(self._buffer) < self._max_buffer_rows` 判断，buffer 已满时暂停 xreadgroup、记录 warning 并等待 flush，TDengine 故障期间新消息保留在 Redis Stream，恢复后自动追读，不丢数据。
- **W-M1 已修复**（`dlq.py`）：`lpush` + `ltrim` 改用 `r.pipeline()` 原子执行，消除半成功时 DLQ 超限一条的风险。

**frontend 模块：**

- **F-H1 已修复**（`ws_push.py` + `realtime/index.vue`）：后端 subscribe 时调用 TDengine 健康检查（30s 缓存），在 snapshot 消息中加 `tdengineConnected: true|false|null` 字段。前端初始值改为 `null`，模板显示"检测中"，收到 snapshot 后更新为真实状态。
- **F-H2 已修复**（`realtime/index.vue`）：`onUnmounted` 写快照前先读取 localStorage 现有 `configs` 字段并保留，避免覆盖 `saveChartSnapshot()` 存入的图表布局配置。
- **F-M1 已修复**（`monitor.py` + `device-monitor.ts` + `realtime/index.vue`）：后端新增首条消息 auth 支持（`{"type":"auth","token":"..."}`，5s 超时），`getRealtimeWebSocketUrl` 去掉 URL token 拼接，WS onopen 后发送 auth 消息，token 不再出现在 URL query string。
- **F-M2 已修复**（`realtime/index.vue`）：新增 `isPerspectiveCleaning` flag，`onUnmounted` 异步清理开始时置 `true`、结束时置 `false`；`updatePerspectiveTable` 检查该 flag，清理期间跳过初始化，消除快速切路由时并发冲突。
- **F-L1 已修复**（`device-monitor.ts`）：删除全项目未使用的 `getDeviceVariablesByGroup` 函数。
- **F-L2 已修复**（`perspective-runtime.ts` + `realtime/index.vue`）：`PerspectiveViewerClient` 类型补充 `save: () => Promise<Record<string, unknown>>`，`save/restore` 调用处去除不再需要的 `as any`。

**backend 模块：**

- **B-M1 已修复**（`tdengine.py`）：新增模块级 `asyncio.Semaphore(5)`，`fetch_all` 用 `async with` 限制最多 5 个并发 TDengine 连接，止血高并发连接开销。
- **B-M2 已修复**（`task_manager.py`）：`_load_tasks` 末尾新增启动时清理逻辑，将残留 `running` 状态的导出任务统一标记为 `failed`（原因"服务重启中断"），避免重启后状态永久卡住。
- **B-M3 已修复**（`history.py`）：历史查询、桶聚合、降采样与明细序列 fallback 路径中的静默 `except Exception` 已补充 `logger.warning`，包含 table 名、device_code、point_id，TDengine 故障时有明确日志可追查。
- **B-M4 已修复**（`history.py`）：v0.6 child table 路径中 `qualify_table`/`quote_identifier` 已移入 try 块，新增 `except ValueError` 单独处理非法列名并记录 warning，防止 ValueError 向上传播。
