## 部署与未验收边界

必须使用 Redis 7.2+、AOF 和允许 WAITAOF 的 ACL，先升级中心再升级边缘。详细语义见 [DW-01 确认语义与持久化边界](../../03-数据与契约/DW-01-确认语义与持久化边界.md)。确认代表 Redis 持久接收，不代表 TDengine 最终入库；未实现最终入库水位及自动对账。拒绝 AOF 确认时保留上游积压，不降级为内存确认。〔⚠️ 适用路径：本条针对**分布式**链路（边缘 Uploader → 中心 Ingest）。**中心式直写路径不需要 `WAITAOF` ACL 授权**，也不等待 AOF fsync（`collector/main.py:181-192`）；不区分形态通读会被误当成全平台要求。〕
