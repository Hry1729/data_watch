# Examples

Perspective provides various examples demonstrating its capabilities:

## Available Examples

- **editable** - File editing example
- **duckdb** - DuckDB integration example
- **fractal** - Fractal visualization
- **market** - Market data visualization
- **raycasting** - Raycasting example
- **evictions** - NYC evictions data
- **nypd** - NYPD data visualization
- **streaming** - Real-time streaming data
- **covid** - COVID-19 data visualization
- **webcam** - Webcam integration
- **movies** - Movies dataset visualization
- **superstore** - Superstore dataset
- **olympics** - Olympics dataset
- **dataset** - Generic dataset examples

## Finding Examples

Examples are available on GitHub in the Perspective repository. Each example demonstrates different features and use cases of Perspective.

## Running Examples

To run the examples, clone the repository and follow the instructions in each example's README file.
